# ABC Company Employee Analysis

## Project Description
A comprehensive data analysis report for ABC Company focusing on employee demographics, team structures, and salary distributions.

## Preprocessing Steps
- **Height Correction**: The original height data was inconsistent. It was replaced with random integers between 150cm and 180cm.
- **Missing Data**: Missing values in the Salary column were filled with the median to ensure calculation accuracy.

## Key Analysis Tasks
1. **Team Distribution**: Calculated headcount and percentage split per team.
2. **Position Segregation**: Classified employees into five main roles (PG, SG, SF, PF, C).
3. **Age Analysis**: Identified the 25-30 group as the most common age bracket.
4. **Salary Expenditure**: Determined which teams and positions consume the most budget.
5. **Correlation**: Visualized the relationship between Age and Salary using scatter plots.

## Insights
- **Predominant Group**: The majority of the workforce is under 30.
- **Top Spender**: The Cleveland Cavaliers have the highest total salary.
- **Position Trends**: Centers (C) command significant salary totals despite being fewer in number.
